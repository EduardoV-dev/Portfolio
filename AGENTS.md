# AGENTS.md

## Stack

- **Monorepo**: pnpm 10 workspaces (`apps/web`, `apps/headless-cms`)
- **Frontend**: Astro 5 + React 19 + TypeScript (strict), plain CSS + PostCSS
- **CMS**: Strapi 5 (SQLite, WIP — not wired to frontend yet)
- **State**: Zustand 5; **Carousel**: Embla
- **Node**: `>=22` required for frontend; pnpm filter name is `web`

---

## Commands

```bash
# Install
pnpm install

# Dev
pnpm dev                          # frontend + strapi in parallel
pnpm dev:frontend                 # Astro only (also: pnpm --filter web dev)
pnpm dev:strapi                   # Strapi only

# Verify — no test suite; use these instead
pnpm --filter web lint            # ESLint
pnpm --filter web typecheck       # astro check (NOT tsc --noEmit)
pnpm --filter web build           # full production build

# Format
pnpm format                       # write fixes (Prettier, whole monorepo)
pnpm check                        # lint + formatcheck + typecheck (no writes)

# Individual (from apps/web or via filter)
pnpm --filter web formatcheck     # prettier --check only
pnpm --filter web check           # lint + formatcheck + typecheck combined
```

No test runner (no Vitest/Jest/Playwright). CI verify = lint + typecheck + formatcheck + build.

## Gotchas

- **`.npmrc` has `ignore-scripts=true`** — Husky won't auto-install. Run `pnpm husky` manually if hooks are missing.
- **Pre-commit runs full build** — every commit triggers `pnpm --filter web build`. Broken build blocks commit.
- **Lint-staged checks format, doesn't fix** — staged files failing `prettier --check` block the commit. Fix: `pnpm format`, re-stage, retry.
- **Typecheck = `astro check`** — no `tsc --noEmit`. Run via `pnpm --filter web typecheck`.
- **`astro check` needs `.astro/types.d.ts`** — generated by first `astro dev` or `astro build`. Fresh clone: run `pnpm dev:frontend` once before typecheck or it errors on missing types.
- **`SITE_URL` env var required** — `apps/web/.env` must have `SITE_URL=http://localhost:3000`. Missing → wrong canonical URLs (no build error).
- **Strapi `.env` required** — needs `APP_KEYS`, `API_TOKEN_SALT`, `ADMIN_JWT_SECRET`, `TRANSFER_TOKEN_SALT`, `JWT_SECRET`, `ENCRYPTION_KEY`.

## Architecture

**Module vs Component split:**
- `src/modules/` — page-section features (e.g. `home/hero/`, `home/ai-assistant/`, `blog/`)
- `src/components/` — reusable cross-page UI (tooltip, card, etc.)

**Path alias:** `@/*` → `src/*`. Use for all internal imports — no relative `../../` across directories.

**Astro islands:** `.astro` files are static by default. Add `client:load` / `client:visible` only when React interactivity is required.

**Frontend data source:** `src/data/projects.ts`, `src/data/posts.ts` (static). Strapi scaffolded but not integrated.

**File layout:** each component/module in its own directory with `index.tsx` or `index.astro` as entry; colocate `index.module.css` (or named `.module.css`) in the same directory.

## Code Style

### TypeScript

- Config: `astro/tsconfigs/strict` — enables all strict flags (`strict`, `strictNullChecks`, `noImplicitAny`, `verbatimModuleSyntax`, etc.)
- `verbatimModuleSyntax: true` — type-only imports must use the inline `type` keyword.
- **Type imports:** inline style only — `import { type Foo }` — never `import type { Foo }`.
- **Props:** use `interface FooProps` for component props; use `type` for union/primitive aliases.
- **Exported interfaces:** `export interface Foo`, not `export type Foo = { ... }`.
- **No `any`:** `@typescript-eslint/no-explicit-any` is `warn`. Avoid it; use `unknown` + narrowing.
- **Bare catch:** intentional — `catch {}` with no variable is idiomatic (error discarded after setting error state).

```ts
// Props → interface
interface TooltipProps {
    text: string;
    position?: "top" | "bottom" | "left" | "right";
    children: ReactNode;
}

// Union aliases → type
type SubmitStatus = "idle" | "submitting" | "success" | "error";

// Inline type import
import { type Post, formatPostDate } from "@/data/posts";
```

### Formatting (Prettier)

- 4-space indent, no tabs
- 100-char print width
- Double quotes everywhere
- Trailing commas in all positions, including function params (`trailingComma: "all"`)
- Semicolons: yes
- `prettier-plugin-astro` handles `.astro` files

### Naming Conventions

- **Files/directories:** kebab-case (`case-study-card/`, `highlights-carousel.tsx`)
- **Components:** PascalCase function name matching directory (`export default function CaseStudyCard`)
- **CSS classes:** BEM in React modules (`block__element--modifier`); flat kebab-case in Astro scoped styles
- **CSS modules access:** bracket notation for BEM names — `styles["block__element--modifier"]`
- **Custom properties:** `--color-*`, `--font-*`, `--ease-*`, `--transition-*` prefixes (defined in `src/styles/global.css`)
- **Zustand stores:** `src/store/*.ts`, exported as `use*Store` hooks

### React Components

- **Declaration:** always `export default function Foo()` — never arrow function components.
- **Helpers inside module:** `function` declarations at module scope, not arrow constants.
- **`useCallback`** for event handlers passed to effects as dependencies.
- **CSS modules:** import last, bracket notation for BEM names.

```tsx
// Correct component pattern
export default function HighlightsCarousel({ items }: HighlightsCarouselProps) {
    const [emblaRef, emblaApi] = useEmblaCarousel({ loop: true });
    const scrollPrev = useCallback(() => emblaApi?.scrollPrev(), [emblaApi]);

    return <div ref={emblaRef} className={styles["highlights-carousel"]}> ... </div>;
}
```

### Astro Components

- `interface Props` declared in frontmatter; `export interface Props` when consumed externally.
- Destructure from `Astro.props` with defaults inline.
- No blank line between `---` fences and the first import.
- `set:html` is **banned** (hard ESLint error: `astro/no-set-html-directive`).
- `aria-hidden="true"` on all decorative elements.

```astro
---
import Header from "./header/index.tsx";
import "@/styles/global.css";

interface Props {
    title?: string;
}

const { title = "Eduardo Varela – Full Stack Engineer" } = Astro.props;
---
```

### Import Ordering

No enforced plugin, but follow this manual order consistently:

1. External library imports (`react`, `clsx`, third-party)
2. Internal `@/` alias imports (store, data, shared modules)
3. Relative sibling imports (co-located helpers)
4. CSS module import — **always last**

```ts
import { useEffect, useState } from "react";           // 1. external
import clsx from "clsx";                               // 1. external
import { useChatStore } from "@/store/chat";           // 2. @/ alias
import styles from "./index.module.css";               // 3. CSS last
```

### CSS

- PostCSS mixins (`postcss-mixins`) — `@mixin` syntax, **not Sass**.
- Breakpoints defined in `src/styles/mixins.css`; import with relative path at top of `<style>` blocks.
- Mobile-first: base styles → `@mixin tablet-up` → `@mixin desktop-up` → `@mixin wide-up`.
- Always include `@media (prefers-reduced-motion: reduce)` guards for animated elements.
- `@keyframes` defined inline in the same `<style>` block as usage.

```css
@import "../../../styles/mixins.css";

.hero__inner { padding: 1rem; }         /* mobile base */

@mixin tablet-up {
    .hero__inner { padding-inline: 1.5rem; }
}

@media (prefers-reduced-motion: reduce) {
    .hero-title { animation: none; }
}
```

**Breakpoints:**
- `tablet-up` — `min-width: 769px`
- `desktop-up` — `min-width: 1025px`
- `wide-up` — `min-width: 1281px`

### Error Handling

- Local status machines over thrown errors: `"idle" | "submitting" | "success" | "error"`.
- Bare `catch {}` — intentional; set error status, don't re-throw.
- Optional chaining as null guard: `emblaApi?.scrollPrev()`, `ref.current?.querySelector(...)`.
- Validation returns `Errors` object (empty = valid); focus first invalid field for a11y.
- Error messages in UI include `role="alert"` for screen readers.

```ts
try {
    const res = await fetch(url, options);
    const data = (await res.json()) as { success: boolean };
    setStatus(data.success ? "success" : "error");
} catch {
    setStatus("error");
}
```

## ESLint Rules (key)

| Rule | Level | Note |
|---|---|---|
| `no-console` | `warn` | `console.warn`/`console.error` allowed |
| `prefer-const` | `error` | |
| `no-var` | `error` | |
| `@typescript-eslint/no-explicit-any` | `warn` | Avoid — use `unknown` |
| `@typescript-eslint/consistent-type-imports` | `warn` | Inline `type` only |
| `@typescript-eslint/no-unused-vars` | `warn` | Ignores `^React$` |
| `astro/no-set-html-directive` | **`error`** | Hard ban |
| `astro/no-unused-css-selector` | `warn` | |
| `react/react-in-jsx-scope` | `off` | React 19 |
| `react/prop-types` | `off` | TypeScript handles it |
