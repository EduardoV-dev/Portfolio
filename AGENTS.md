# AGENTS.md

## Stack

- **Monorepo**: pnpm 10 workspaces (`apps/frontend`, `apps/strapi`)
- **Frontend**: Astro 5 + React 19 + TypeScript (strict), plain CSS + PostCSS
- **CMS**: Strapi 5 (SQLite, WIP — not wired to frontend yet)
- **State**: Zustand 5; **Carousel**: Embla
- **Node**: `>=22` required for frontend; pnpm filter name is `apps-frontend`

## Commands

```bash
# Install
pnpm install

# Dev
pnpm dev                   # frontend + strapi in parallel
pnpm dev:frontend          # Astro only
pnpm dev:strapi            # Strapi only

# Verify (no test suite — use these instead)
pnpm --filter apps-frontend lint        # ESLint
pnpm --filter apps-frontend typecheck   # astro check (no tsc --noEmit)
pnpm --filter apps-frontend build       # full build

# Format
pnpm format                # write (Prettier, whole monorepo)
pnpm check                 # lint + prettier check, no writes

# Focused (from apps/frontend)
pnpm check                 # lint + formatcheck + typecheck
```

No test runner (no Vitest/Jest/Playwright). Verify = lint + typecheck + build.

## Gotchas

- **`.npmrc` has `ignore-scripts=true`** — Husky won't auto-install on `pnpm install`. Run `pnpm husky` manually if hooks missing.
- **Pre-commit runs full build** — every commit triggers `pnpm --filter apps-frontend build`. Broken build blocks commit.
- **Lint-staged checks format, doesn't fix** — staged files failing `prettier --check` block commit. Fix: `pnpm format`, re-stage, retry.
- **Typecheck = `astro check`** — no `tsc --noEmit`. Run via `pnpm --filter apps-frontend typecheck`.
- **`astro check` needs `.astro/types.d.ts`** — generated by first `astro dev` or `astro build`. Fresh clone: run `pnpm dev:frontend` once before `typecheck` or it errors on missing types.
- **`SITE_URL` env var required** — `apps/frontend/.env` must have `SITE_URL=http://localhost:3000`. Missing → wrong canonical URLs in build (no build error).
- **Strapi `.env` required** — needs `APP_KEYS`, `API_TOKEN_SALT`, `ADMIN_JWT_SECRET`, `TRANSFER_TOKEN_SALT`, `JWT_SECRET`, `ENCRYPTION_KEY`.
- **CSS uses PostCSS mixins** — `@mixin` syntax from `postcss-mixins`, not Sass. Defined in `src/styles/mixins.css`.
- **Prettier config**: 4-space indent, 100-char width, double quotes, `trailingComma: "all"` (including function params). Deviating breaks CI format check.
- **`astro/no-set-html-directive`** hard ESLint error — don't use `set:html` in `.astro` files.
- **`consistent-type-imports`** ESLint rule enforces inline style: `import { type Foo }`, not `import type { Foo }`.

## Architecture

**Module vs Component split:**
- `src/modules/` — page-section features (e.g. `home/hero/`, `home/ai-assistant/`)
- `src/components/` — reusable cross-page UI

**Path alias:** `@/*` → `src/*`. Use for all internal imports.

**Astro islands:** `.astro` files static by default. Add `client:load` / `client:visible` only when React interactivity needed.

**ESLint layering:** Root `eslint.config.mjs` is base. `apps/frontend/eslint.config.mjs` extends with Astro, React, React Hooks, jsx-a11y rules.

**Frontend data source:** `src/data/projects.ts` (static). Strapi scaffolded, not integrated.

## CI/CD

- **PRs to `main`/`development`**: lint → typecheck → formatcheck → build (runs in `apps/frontend`)
- **Push to `development`**: deploys to AWS S3 + CloudFront via OIDC
- **Branch model**: feature → `development` (deploy target) → `main` (production gate)
